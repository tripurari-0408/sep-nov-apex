# Task 1: Data Immersion & Wrangling

## 📌 Project Overview
This repository contains the complete workflow and deliverables for **Task 1: Data Immersion & Wrangling** of the ApexPlanet Data Analytics Internship. The primary objective is to acquire raw transactional sales data, perform comprehensive quality profiling, apply cleaning and feature engineering transformations, and produce an analysis-ready dataset.
